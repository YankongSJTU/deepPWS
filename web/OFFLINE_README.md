# DeepPWS 单机离线版（Windows x64）

此版的界面、Python、推理依赖、模型权重和三维计算图都在同一文件夹中。推理、照片保存和报告生成在当前电脑完成，不连接 GPUT6，不使用 SSH，不需要安装 Python 或联网下载模型。

## 使用

1. 将整个 `DeepPWS_Offline_Windows` 文件夹复制到 Windows 10/11 的 64 位电脑的可写目录，例如桌面或数据盘。
2. 双击 `Start_DeepPWS.bat`。首次启动可能稍慢，程序会自动打开本机浏览器。
3. 填写病例与临床信息，上传治疗前后照片，点击“一键分析”。

病例编号默认按当前电脑时间自动生成，支持修改。医生填写的年龄与 Fitzpatrick 分型优先使用；留空时，新增独立照片模型估计年龄与病历 III/IV 标签，作为本次评分输入。结果页清楚区分“模型估计，待核对”和“医生填写”，并可直接确认或修正，复用图像缓存更新评分。原始输入与本次有效输入分别保存，不把预测伪装为原始病历。性别仅手动填写，留空为未记录，不从外貌推断。

年龄模型使用上海源队列训练，按患者分组的五折验证 MAE 约 2.82 岁；重庆、浙江直接测试 MAE 约 2.84、3.38 岁。估计范围为训练数据的 1–61 岁，不能视为患者真实年龄。III/IV 模型仅拟合既有病历标签，不覆盖 I、II、V、VI；上海分组验证宏 F1 约 0.634、AUC 约 0.743，浙江直接测试宏 F1 约 0.651；重庆只有 III 型标签，无法验证 IV 型识别。Fitzpatrick 本身涉及晒伤/晒黑反应，照片候选不能替代医生评估。分型依据：https://dermnetnz.org/topics/skin-phototype 。上述为既有队列上的探索性验证，不是新增独立盲法验证。

并发症、拍照间隔均可留空，只接受医生手动输入，不由模型预测。间隔以天记录；也可由医生填写的前后照片日期计算。它们不作为评分输入。

2026.10.25 版增加治疗前照片的病灶颜色、侧别、三叉神经分区和粗略区域候选。默认使用上海源模型；重庆选项仅替换颜色分支，浙江选项仅替换神经分区输出头，均为小样本研究适配版本。可以关闭候选识别。模型分数未经概率校准，不等于临床准确率，外中心适配结果尚未经过独立盲法验证。

颜色或神经分区仍需勾选并点击“确认所选候选并更新评分”后填入；年龄和 III/IV 标签的自动填补使用独立的结果页核对区。侧别和粗略区域供参考，不自动改写精细病灶部位。不包含病灶分割。旧版病例继续保留，重新分析后可生成新版估计。

界面默认地址是 **http://127.0.0.1:8875**；若旧版仍占用该端口，新版自动使用下一可用本机端口，例如 8876，启动窗口会显示实际地址。这是本机地址，并非互联网网站；电脑断网也可以打开。运行时请保留启动窗口，关闭窗口即停止本机服务。更新前请结束旧版的分析任务，使用新版后关闭旧版窗口，避免同时操作同一病例。

不要只复制启动文件，也不要直接在压缩包中运行。保持文件夹内部结构完整。新电脑第一次运行不需要 pip 安装、激活虚拟环境、输入服务器账号或连接隧道。

## 启动入口

| 文件 | 用途 |
|---|---|
| `Start_DeepPWS.bat` | 默认启动：有可用 NVIDIA GPU 时使用 GPU，否则使用 CPU |
| `Start_DeepPWS_CPU.bat` | 强制仅使用 CPU |
| `Check_Environment.bat` | 检查包内 Python、权重和本机运行设备 |

有 NVIDIA 显卡且驱动兼容时可获得更快速度。无需单独安装 CUDA Toolkit；包中包含 PyTorch 运行所需的 CUDA 用户态库。系统显卡驱动仍由电脑提供。没有兼容显卡时可用 CPU，完整模型的 CPU 分析会明显更慢。

此包针对 Windows x64 制作，不能直接当作 Linux 或 macOS 程序运行。建议使用内存充足的近年电脑；实际速度取决于 CPU、GPU、磁盘和上传视图数量。

## 包含内容

- `python/`：独立 CPython 3.12.8、PyTorch 2.6.0、torchvision、NumPy、SciPy、OpenCV、FastAPI 及依赖；通过独立 `_pth` 配置与系统 Python 隔离。
- `models/`：校正队列 813 条记录/774 组的冻结 Ridge 参数和临床编码。
- `clinical_models/`：约 15 MB 的三成员临床识别参数、重庆颜色适配和浙江神经分区输出头适配；纯数值 NPZ，不含患者照片或标识。
- `demographic_models/`：年龄与病历 III/IV 标签的冻结数值模型和按患者分组的验证指标；不含性别推断模型。
- `standalone_models/lam_encoder.pt`、`lam_decoder.pt`：包含原三维分支全部实际推理权重和固定中性查询点的独立计算图，运行时无需 PyTorch3D、FLAME Python 模型或远程仓库。
- `runtime/`：CLIP、FaRL、面部配准及区域统计所需的本地资源。
- `backend/`、`vendor/`、`web/`：服务、特征提取和中文界面。
- `data/`：首次使用后生成。保存病例库、上传照片、分析中间结果及报告资料。交付包不包含研究患者的照片或病例库。

复制到其他电脑时，若要同时迁移已有病例，也需要复制自己的 `data/` 文件夹；若要空白部署则不要携带该文件夹。病例资料不会自动发往其他电脑。

## 模型一致性与离线检查

保留原来的 CLIP、FaRL、面部配准、Lab 残差、三维/UV 和固定 Ridge 评分流程，没有改成其他图像模型或删去三维分支。三维计算图导出测试与原流程逐项对比的最大绝对误差为 0；查询分块只控制计算峰值内存，不删除查询点。

离线入口禁用程序内的外网连接和外部 DNS，仅允许 localhost/loopback。没有自动下载权重的逻辑，界面不依赖 CDN、在线字体或服务器 API。临床信息中的性别、治疗次数、并发症等仍作为病例/报告字段；模型仅使用其原有训练字段。

此前版本同一组真实照片实测：RTX 4060 约 35 秒，CPU 约 7 分 12 秒。CPU/GPU 浮点运算与 UV 像素取整存在微小差异，该测试最终评分的最大绝对差约 0.0054 分；不声称不同设备逐比特一致。新版运行耗时见 `OFFLINE_UPDATE_VALIDATION_20261025.json`。这些只是当前电脑和测试照片的耗时，不代表所有电脑的速度。

`OFFLINE_VALIDATION.json` 汇总当前已完成的本机运行、真实照片及路径迁移验证；`standalone_models/export_validation.json` 提供模型导出误差与文件指纹；`BUNDLED_ENVIRONMENT.json` 列出内置依赖版本。尚未在第二台实体电脑上测试。

`clinical_models/export_validation.json` 记录临床参数与训练端的数值对比，最大绝对误差小于 0.0000005；这验证导出一致性，不代表临床性能。

随附模型和第三方组件保留各自许可；不得通过移除必要资源来缩小文件夹后仍声称是完整模型推理。

## 大图上传（2026.10.26-resize1）

单张文件上限为 100 MB，支持最大 3 亿像素。超过 3000 万像素的照片由后台按比例缩至最长边 4096 像素，再进行分析；自动纠正 EXIF 方向，不拉伸、不裁剪。JPEG 优先使用解码器降采样，缩放后以高质量保存。3000 万像素以内照片保持原文件不变。被缩小照片的上传原件保存在病例目录 `originals/`，分析使用缩小副本；报告记录原始尺寸、分析尺寸及缩图提示。浏览器只生成小尺寸预览，预览失败也可提交给后台处理。

缩放和 JPEG 重编码可能产生轻微像素变化，新增大图输入按以上流程评估；既有小图流程和模型参数不变。

## 关键点配准对比与 Excel（2026.10.26-workbench1）

“治疗前后影像对比”默认显示首组视角的关键点配准图：以治疗前照片为参考，按双眼中心计算治疗后的等比例缩放、旋转和平移。双眼中心对齐，鼻部及稳定关键点的均方根误差均须不超过眼距的 8%，面部有效覆盖须达到 90%；超过阈值时明确提示未通过检查，并显示未配准的原始视角。二维配准不能保证不同三维视角或表情下全部关键点重合，不做局部形变来强行贴合病灶。

可切换“配准＋关键点”核对绿色与橙色标记，或切回原始视角；“同步放大”同时缩放前后两张图，保持配准关系。旧记录打开时会自动补生成配准图，单独运行关键点检测，不改写原来的特征或评分。配准仅用于浏览，评分继续使用原有图像和计算流程。

在“分析记录”中，点击“导出全部已完成”导出所有已完成记录，不受搜索条件限制；或逐行勾选后点击“导出选中”。表头复选框只勾选当前筛选结果中的已完成记录，已选项可跨搜索保留。未分析、失败或正在分析的记录不能导出。Excel 为真正的 `.xlsx`，包含“分析记录”和“导出说明”两个工作表，首行冻结并提供筛选；临床资料、三项评分、候选预测、医生输入、本次有效输入及来源分列。仅导出表格数据，不包含照片。生成 Excel 不需要额外安装依赖或联网。
